# GMA.github.io

This is a basic personal website project that includes multiple pages to showcase various aspects of an individual's professional profile.

## Project Structure

```
my-website
├── src
│   ├── index.html         # Home webpage
│   ├── education.html     # Education webpage
│   ├── experience.html     # Experience webpage
│   ├── portfolio.html      # Portfolio Projects webpage
│   ├── css
│   │   └── styles.css      # Styles for the website
│   └── js
│       └── main.js         # JavaScript for interactivity
├── package.json            # npm configuration file
└── README.md               # Project documentation
```

## Features

- **Home Page**: An introduction and overview of the individual.
- **Education Page**: Details about educational background and qualifications.
- **Experience Page**: Information about work experience and professional history.
- **Portfolio Projects Page**: Showcase of projects and accomplishments.

## Getting Started

To get started with this project, clone the repository and open it in your preferred code editor. You can run the website locally by opening the `index.html` file in a web browser.

## Installation

If you want to manage dependencies or run scripts, you can use npm. Make sure you have Node.js installed, then run:

```
npm install
```

## Usage

Open `src/index.html` in your web browser to view the website. Navigate through the different pages using the links provided in the navigation menu.
